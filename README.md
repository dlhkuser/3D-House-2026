# 3D House 2026

An interactive 3D model of a single-storey, four-bedroom house, drawn from its approved floor plan. It runs in the browser with no build step: open `index.html`.

- **index.html**: the 3D model (three.js). Orbit, fly to any room, or walk through. Arrange the furniture from an inventory, choose finishes, and switch between day and night lighting. There is also a Standard / High quality setting. Layouts can be exported to and imported from JSON files.
- **floor-plan.html**: the 2D floor plan, with internal room sizes.

The interior finishes are typical choices, not the house's actual ones. Saving layouts to an account only works when the page is opened as a Claude artifact. Opened anywhere else, layouts are kept in the browser and can still be exported as files.
